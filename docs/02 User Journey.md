# User Journey

> 状态：Draft

## 1. 创建项目

用户上传小说并设置风格、9:16 画幅、单集时长、镜头预算、改编强度、受众与内容尺度。

## 2. 审阅小说圣经

系统生成结构化的世界观、剧情、人物、地点、道具、时间线和章节事件。用户修正人物合并、关系、昵称、外观或不拍摄的支线后再确认；确认的数据供后续所有步骤使用。

## 3. 规划分集

系统生成 Season/Episode 规划和每集的钩子、冲突、高潮、悬念。用户可改变集数、时长和剧情归属，并只重生成被修改的一集。

## 4. 审阅剧本与分镜

用户在分镜表或时间线上编辑 Scene 和 Shot，而不是修改 Prompt 文件。镜头中可直接调整角色状态、构图、景别、动作、台词、时长、参考资产和 Provider 建议。

## 5. 确认资产库

系统生成角色与场景标准资产；用户审核通过后，后续镜头复用这些资产和状态版本。

## 6. 批量生产

系统按镜头类型选择 Provider，排队生成图片、视频和语音。独立镜头可并行，依赖上一镜头尾帧的连续镜头按依赖顺序执行。

## 7. 审片与返工

系统自动检测人物、脸部、服装、人数、动作、视频质量、口型、字幕、配音和镜头连续性。低质量镜头进入重试队列；用户只介入待确认镜头或主动重做指定镜头。

## 8. 剪辑与导出

系统按分镜时长自动拼接镜头、旁白、配音、字幕、BGM 和音效，支持 J-cut、L-cut 与基础转场，导出 9:16 成片及可继续编辑的工程数据或独立素材与时间线描述。
