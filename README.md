# AI Director OS

把故事自动、高质量地转化为影视内容——不是「小说转视频工具」，
而是一套数字影视制作系统：导演、编剧、美术、摄影、配音、剪辑、审核
由 AI Agent 协同完成，用户负责创作故事。

输出形态包括 AI 短剧、AI 动漫、AI 漫画——**影视只是其中一种**。
